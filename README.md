# 📌 Overview

AlgoAssist AI helps businesses automate customer support through an AI-driven chatbot system.

The chatbot can:
- Answer customer queries instantly
- Provide real-time assistance
- Improve customer experience
- Reduce manual support workload

Built with modern web technologies, AlgoAssist AI focuses on performance, scalability, and user-friendly design.

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/supritam1/algoassist-ai.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd algoassist
```

## 3️⃣ Install Dependencies

```bash
npm install
```

---
